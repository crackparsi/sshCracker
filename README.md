🔐 SSH Cracker
Developed by @CrackParsi

یک ابزار قدرتمند و سریع برای تست نفوذ و بروت‌فورس SSH با قابلیت تشخیص خودکار هانی‌پات (Honeypot). این ابزار با استفاده از زبان Go و همزمانی (Concurrency) بالا، توانایی اسکن و کرک هزاران هدف را با کمترین مصرف منابع دارد.

✨ ویژگی‌ها
⚡ سرعت بالا: موتور همزمان با atomic operations (بدون قفل‌گذاری) برای سرعت ماکزیمم.
🧠 تشخیص هانی‌پات: شناسایی و عبور خودکار از سرورهای فیک (Cowrie, Kippo و غیره).
📊 داشبورد زنده: نمایش لحظه‌ای سرعت، زمان باقی‌مانده و پیشرفت.
📱 ارسال به تلگرام: ارسال مستقیم سرورهای کرک شده و اطلاعات کامل سیستم به تلگرام.
🔄 قابلیت رزوم: ذخیره و ادامه عملیات کرک در صورت قطع شدن.
🚀 راهنمای اجرا
فایل‌های کامپایل شده برای ویندوز (exe.) و لینوکس در شاخه اصلی قرار دارند.

برای لینوکس:
git clone https://github.com/crackparsi/sshCracker.git
cd sshCracker
chmod +x ./sshCracker
./sshCracker
برای ویندوز:
فایل sshCracker.exe را اجرا کنید. (در صورت پاک شدن توسط آنتی‌ویروس، آن را در Exclusions قرار دهید).

📁 فایل‌های خروجی
good.txt : تمام رمزهای عبور پیدا شده
real_servers.txt : سرورهای واقعی با اطلاعات کامل (RAM, CPU, Location)
errors.txt : لاگ خطاها
⚠️ هشدار
این ابزار صرفاً برای اهداف آموزشی و تست نفوذ مجاز طراحی شده است. نویسنده هیچ مسئولیتی در قبال misuse این ابزار ندارد.
